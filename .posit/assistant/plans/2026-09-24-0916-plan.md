# Redesign OECD comment notification

## Context
`app.R` currently renders a `comment_flag` badge next to each indicator's
label in the heatmap row when `oecd_comments` has an entry for that
country/measure (see `comment_flag` computed around line 3666, used at the
label div around line ~3799). It's currently a full pill badge:
"💬 OECD comment" with background `#FFF3CD`, border `#F5C518`, rounded
corners, and padding — the user finds this too large/obtrusive.

## Goal
Replace the pill badge with a smaller, less obtrusive notification that
still clearly signals "click to see an OECD comment" via a hover tooltip,
without taking up much horizontal space in the compact heatmap row.

## Options to choose from (pick one, or suggest a variant)

- **A — Small dot/asterisk**: a single colored marker (e.g. a filled dot
  "●" or asterisk) in amber/gold, ~8-9px, placed right after the label
  text. All meaning conveyed via tooltip on hover.
- **B — Icon only, tinted circle**: keep an icon (💬 or ℹ️) at ~13-14px,
  no text label, optionally with a small tinted circular background so
  it's still easy to spot at a glance without the pill shape/border.
- **C — Superscript marker**: a compact circular marker (icon or dot)
  positioned as superscript to the top-right corner of the label text,
  like a footnote marker — adds no horizontal space to the row.
- **D — Dotted underline on label text**: no added icon; give the
  indicator label a dotted underline in muted gold when a comment exists,
  with the tooltip on hover. Most subtle, least discoverable.

## Implementation (once an option is chosen)
1. Edit the `comment_flag` computed column in `app.R` (~line 3663-3678) to
   render the chosen minimal style instead of the current pill badge.
   Keep the existing `title=` tooltip text ("The OECD left a comment on
   this indicator — click to open the panel and read it").
2. If Option D is chosen, instead modify how `label` is wrapped/styled at
   the row-label div (search for where `label, comment_flag` are
   concatenated into the row's label `<div>`), rather than adding a
   separate `comment_flag` span.
3. Verify `app.R` still parses (`parse("app.R")`) after the edit.
4. No changes needed to `oecd_comments`/`oecd_reasons` loading logic or to
   the in-panel "OECD Comment" box — only the row-level notification
   changes.

## Out of scope
- The full OECD Comment box shown inside the expanded panel is unaffected.
- No changes to `global.R` or data loading.
