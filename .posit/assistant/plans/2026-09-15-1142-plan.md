# Static demo version of the Data Request Portal

## Goal

Create a standalone demo copy of the app at
`/Users/Kate/OneDrive/WISE/Data request portal/data-request-portal-static` with:

- **No login page** — visitors land directly on the main app
- **No admin page** or admin functionality
- **No data collection** — no Google Drive, no pins, no server-side saving of any kind
- **No memory between sessions** — values entered update the UI live, but everything is wiped on reload (this falls out naturally from Shiny once persistence is removed: state lives only in per-session `reactiveValues`)
- **Fixed example country**, completely blank (no prefilled previous responses or OECD comments)
- **Excel template download kept; upload removed**

## Approach

The app's persistence is already funneled through `session_read()` / `session_write()` helpers in `global.R`, and every optional data file (`previous responses.RDS`, `oecd_comments.xlsx`, `latest request.RDS`, `time use submissions.RDS`, `non-used responses.RDS`) is loaded behind a `file.exists()` guard with an empty fallback. So the static version is mostly:

1. copy the project, excluding secrets/session folders and the prefill data files,
2. stub the storage layer (reads return `NULL`, writes are no-ops that return `TRUE`),
3. remove login/admin UI and handlers, auto-authenticating a fixed demo country.

### Fixed demo country

Use a fictional country: `credentials$country = "DEMO"`, `credentials$country_name = "Demo Country"` (label adjustable). Benefits:

- All lookups into the published dataset (`ref_area == "DEMO"`) return nothing → forms and heatmap start blank, exactly as requested.
- `"DEMO"` is not in `eu_silc_countries`, so the **full** set of measures is shown — best for giving countries an idea of everything they might be asked for.
- `latest_request` has no entry for it → the "starts unpopulated" path already in the code is used.

The cross-country **Well-being Data Coverage** tab (published data across countries) stays as-is — it's public data and useful context for the demo.

## Steps

### 1. Copy the project

Copy `data-request-portal/` → `data-request-portal-static/`, **excluding**:

- `drive-token/` (OAuth secret), `sessions/`, `rsconnect/`, `.git/`, `.Rproj.user/`
- `data/previous responses.RDS`, `data/oecd_comments.xlsx` (blank demo, no real country responses shipped)
- `data/latest request.RDS`, `data/time use submissions.RDS`, `data/non-used responses.RDS` (all have empty fallbacks)

Keep: `app.R`, `global.R`, `www/`, and the structural data files (`dictionary.xlsx`, `definitions.xlsx`, `response_input.RDS`, `final dataset.RDS`, `5_5 Request data.RDS`, `oecd average.RDS`).

Rename the `.Rproj` file to `data-request-portal-static.Rproj`. Add a fresh minimal `.gitignore`.

### 2. `global.R` — remove persistence layer

- Delete the pins / Google Drive / mirai sections (roughly lines 9–152): board setup, `session_write_async`/`session_read_async`, `frozen_map_*`, `session_list_*`.
- Drop `library(pins)`.
- Replace with no-op stubs so the rest of the code needs minimal changes:

```r
# Static demo: no persistence. Reads find nothing; writes succeed silently.
async_board_enabled <- FALSE
session_read   <- function(name) NULL
session_write  <- function(x, name) TRUE
session_delete <- function(name) TRUE
session_list_countries <- function() character(0)
session_list_all       <- function() character(0)
frozen_map_read <- function() list()
frozen_map_set  <- function(iso, frozen) TRUE
```

- Everything else in `global.R` (measure config, row defs, validation, time-use tables, coverage counts) stays unchanged. The prefill blocks already degrade to empty lists when their files are absent.

### 3. `app.R` — remove login

- Delete the login screen UI (~lines 775–836) and the login/admin-toggle JavaScript (~lines 457–479).
- Un-hide the main app div (remove `shinyjs::hidden()` around `main_app`, ~line 840).
- Delete the login observer (~lines 1553–1683) and the change-password modal handler (~line 1708).
- At the top of the server, auto-authenticate:

```r
credentials <- reactiveValues(
  authenticated = TRUE,
  country       = "DEMO",
  country_name  = "Demo Country"
)
```

- All existing `req(credentials$authenticated)` guards then pass without further edits.
- Remove any logout / change-password buttons from the header UI.

### 4. `app.R` — remove admin

- Delete the admin app UI div (~lines 1326–1419).
- Delete admin server handlers: data table/download, freeze–unfreeze controls, session backup ZIP download, restore upload (~lines 4614–4633), reset-all (~lines 4664–4667), and any `admin_auth` reactive.
- Remove the 30-second freeze-polling observer (~lines 2037–2047) and the frozen-banner logic (the stubbed `frozen_map_read()` would make it inert anyway, but removing it avoids pointless polling).

### 5. `app.R` — no data collection

- Keep the "Save and continue" / "Submit" buttons functioning **against in-session state only**: the existing `session_data` reactiveValues keep working; the `session_write()` calls they trigger become no-ops. So entered values update the heatmap/status within the session and vanish on reload — exactly the requested behavior.
- Remove the Excel **upload** control and its server handler (Step 2 upload, ~lines 935–994 UI region); keep the template **download** and record-copy download.
- Remove the feedback submission feature if it writes to the `feedback` pin (writes would silently no-op, but better to remove the UI so users aren't misled that feedback is received).

### 6. Demo banner

Add a small persistent banner (styled via existing stylesheet) at the top of the app:

> "Demo version — for illustration only. Nothing entered here is saved or submitted, and all values are cleared when the page reloads."

Adjust wording as you like.

### 7. Verify

- `shiny::runApp()` the static copy; confirm:
  - lands directly on the main app, no login
  - all tabs render for the demo country with blank forms
  - entering values updates the panel/heatmap state live
  - template + record-copy downloads work; no upload control present
  - reloading the page wipes everything
  - no `drive-token/`, no writes to disk, no admin route reachable
- `grep` the static copy for `pins`, `googledrive`, `gargle`, `mirai`, `admin2026`, `oecd2026` to confirm nothing sensitive or persistence-related remains.

## Deployment note (out of scope, for later)
